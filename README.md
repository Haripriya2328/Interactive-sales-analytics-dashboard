# 📊 Sales Analytics & Prediction Dashboard

This project is an interactive Sales Analytics Dashboard built using Python, Pandas, Matplotlib, Streamlit, and Machine Learning.

The dashboard analyzes:
- Product-wise sales
- Region-wise sales
- Date-wise sales trends
- Monthly sales analysis

It also predicts future sales using Linear Regression.



## 🚀 Features

- Interactive Streamlit dashboard
- KPI cards
- Product & region filters
- Date-wise sales trend analysis
- Monthly sales analysis
- Product distribution charts
- Machine Learning sales prediction
- Actual vs predicted trend visualization
- Download filtered data option
